# Original script written for the Pebble demo. One line per transcript segment.
# Scene: a friend asks why the speaker built Pebble. A = friend, B = Pebble's designer.
# Format: SPEAKER: text   (speakers map to voices in scripts/build-demo-fixture.mjs)
A: 哎，你最近是不是在搞个什么 app？朋友圈老看你发。
B: 对！叫 Pebble，是一个中文学习工具，专门把播客转录并翻译成英文。
A: 有点东西啊。你怎么突然想做这个？
B: 其实就是解决我自己的痛点。我平时在小宇宙上听播客学中文，但 app 里根本没有翻译功能，根本学不了。
A: 懂，那卡点确实挺窒息的。那你现在中文什么水平？
B: 我目前在准备 HSK 5，想通过大量的输入来学，比如播客。但听不懂的地方，没法查，没法记，干着急。
A: 所以你就干脆自己做了一个？
B: 对，一开始就是自用。做设计的人嘛，遇到问题第一反应就是——那我来设计个解决方案。
A: 绝了，这就是吃自己的狗粮啊。那 Pebble 具体能干啥？
B: 它可以转录你自己的播客音频，逐句翻译成英文，还能对照着看。这样我就能一边听一边学。
A: 听起来很实用。所以你的 mission 是啥？
B: 就是让学中文的人，能直接从真实的播客内容里学。原汁原味的语料，比课本香多了。
A: 可以可以，那这个必须给我安排一个。
B: 哈哈，蹲着吧，等我上线。
